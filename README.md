# Coffee 101

A personal, French-language coffee companion, created as a birthday gift to accompany coffee beans. Designed primarily for iPad and desktop.

## The journey

1. **Préparer** — the landing page: make a satisfying coffee, starting with an automatic bean-to-cup machine that makes espresso only.
2. **Explorer** — discover coffee origins through an interactive Earth globe and an accessible origin list.
3. **Déguster** — learn to describe coffee gently and keep a personal tasting notebook.

## Current status

Planning and design handoff. No application stack, dependencies, hosting, or backend have been selected. No application has been implemented yet.

The agreed direction is a contemporary coffee atlas: Bauhaus-inspired geometry, topographic accents, selective glassmorphism, and one restrained liquid-morph transition.

## Start here

Read the project brief and Copilot instructions before changing code. First propose the architecture, implementation plan, and stack tradeoffs. Wait for the owner's approval before scaffolding the application or installing dependencies.

Discussion and development documentation can be in English. Every user-facing part of the app must be in natural French.
